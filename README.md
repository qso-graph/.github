# QSO Graph: organization defaults

This repository holds what every QSO Graph repository shares:

- **`profile/README.md`**: the page at [github.com/qso-graph](https://github.com/qso-graph).
- **`TEMPLATES.md`**: how every repository is built, released and presented, starting with
  *What every public repository carries*.
- **`.github/`**: the default issue forms, pull request template, `SECURITY.md` and `CONTRIBUTING.md`,
  which GitHub uses in any repository that has none of its own.
- **`scripts/`**: weekly checks across the organization: `drift_check.py` (a release published
  everywhere) and `conformance.py` (each public repository against *What every public repository
  carries*).

The documentation for users is at [qso-graph.io](https://qso-graph.io).
